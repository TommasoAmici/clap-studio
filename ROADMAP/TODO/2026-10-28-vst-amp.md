## Implementation context

The Ableton Amp reference describes gain-driven distortion, tone shaping, output
level and a dry/wet balance. This amplifier offers those useful controls as a
simple stereo saturator; it does not claim to model Ableton's seven amp circuits
or speaker cabinets. See [README](../../README.md) for the musician-facing flow.

`BuiltInEffect` supplies named recipes and the `BuiltInProcessor` interface;
`AmpProcessor` keeps separate left and right tone-filter state. Live preview
reuses a processor across blocks and parameter changes; bounce creates a fresh
processor per effect and per sample. Both follow the same chain order and bypass
rules as VST3 effects and never modify source files. New built-ins register in
`BuiltInEffect` and provide their own parameter defaults and processor.

`BuiltInAmpTests` covers wet/dry mixing, saturation, live updates and bypass,
and a helper-process bounce that preserves the source.
The mixed-chain live test covers order, bypass and saved settings with the VST3
gain fixture. Light and dark debug snapshots on macOS 26.7.2 show the four
controls; the larger card avoids hiding Dry/Wet. macOS 14 and 27 runtime
checks, keyboard navigation and an audible hardware audition were not available.
