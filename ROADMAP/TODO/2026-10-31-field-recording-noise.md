# Field recording noise

Sometimes field recordings have some background noise. It'd be great to have a way
to remove it.

Please build a feature to denoise field recordings using DeepFilterNet3:
see https://github.com/Rikorose/DeepFilterNet or https://huggingface.co/iky1e/DeepFilterNet3-MLX

This should be an option in the context menu of field recordings.
It should also be presented in the inspector sidebar of field recordings.

Make sure the model is bundled in the final build.
