# Images for website and media kit
Please seed the app with samples and take screenshots of different views in both light and dark mode.
These images will be shown in our social media and our website so they must be high resolution images.
Store the screenshots in ./media in this repo.

Ideally, we should end up with a script we can run in the future to update the screenshots. So when the UI changes, we can regenerate these screenshots to include the changes.
